## How I work

- **Business question first.** I start with what decision the analysis supports, not with which tool to use.
- **Reproducible by default.** Analysis is scripted, documented, and rerunnable. Results trace back to source.
- **Validation before reporting.** Metrics are checked before they reach a dashboard or a stakeholder.
- **Honest about limitations.** Assumptions, data-quality issues, and uncertainty are documented alongside results, not hidden underneath them.
- **Communication matters.** A finding only a statistician can interpret is half-finished.
